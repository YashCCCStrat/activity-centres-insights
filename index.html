Purpose

Four questions

The review of Casey’s Activity Centres Strategy (2020) needs to understand the State’s direction for activity centres, especially the Great Places theme and “community and place” outcomes. Reading a few key documents shows what each asks for. It cannot show how the wider body of planning writing connects these ideas, or where Casey’s documents sit within it.

This analysis asks four questions:

  1. Which themes do Victorian activity centre documents give most attention to?
  2. Which themes are discussed together, and which are kept apart?
  3. Which themes connect the rest, and which are isolated?
  4. Where do Casey’s documents sit, and what does that mean for “community and place”?

It does not choose a direction for the review. It is evidence for that choice.

Method

A directed content analysis of documents as data, followed by a thematic network analysis. It follows the NVivo workflow, with each query scripted so the whole analysis re-runs when documents are added.

14 · Discussion

What it means for community and place

Two registers, and a missing link

Victorian activity centre documents allocate growth in one vocabulary and describe places in another. The network register is anchored by economy and centre hierarchy (w = 230): in most strategies a centre’s rank is its retail and employment role. The place register is a dense bundle of public realm, built form, walkability, housing and inclusion. Each is coherent; the difficulty is the link between them.

What carries the link

Public transport is the theme both registers rely on (betweenness 0.315). Inclusion & safety (0.246) and Place identity (0.175) are the other bridges, and both are thin. A strategy that weakens these also weakens the connection between where growth goes and what places become.

Community: the weaker half of “community and place”

Engagement has 1 significant tie(s). Community facilities connect to economy and inclusion, not to walkability or public realm, although Casey’s facilities framework asks for facilities within a 20-minute journey and integrated with public space. Community is treated as consultation and service provision, not as part of how centres are designed.

Country

Country connects only through place identity and never meets the centre hierarchy (w = 0); it is negatively associated with economy (φ = -0.152). Plan for Victoria and Movement and Place expect Traditional Owner knowledge to shape places from the outset; the corpus shows how far practice is from that.

Scale

Structure plans and the recent State program documents join the two registers on most of their pages, so integration is achievable when a document plans a specific place. For a municipal strategy, the task is to carry that precinct-scale integration up to the network: to let place, community and Country inform the hierarchy, not only the design guidelines.

Limits

What this can and can’t show

  • Coding. Codes find words, not meaning. A table of “health care” jobs is coded to community facilities; a page about walking that never uses the listed terms is missed. Precision about 80%; recall not measured; no intercoder test.
  • Corpus. A working reading list, not a systematic sample. Peer economic strategies from one consultancy are over-represented.
  • Page as unit. Dense pages co-code more themes, which raises weights for text-heavy documents.
  • Association, not cause. Co-occurrence shows what is discussed together, not what shapes what.
  • Saturation. Measured within a fixed codebook, in coding order.
  • Position. Prepared within the team reviewing the strategy. The negative cases and robustness check are the main safeguards.

Appendix C

Replicate it in NVivo and Gephi

NVivo 15

  1. Files and cases. Import each PDF into a folder for its stratum; create a Case per file with attributes Stratum, Author, Year and Pages.
  2. Codebook. Create the 15 parent and 81 child codes; write a definition memo for each parent.
  3. Auto-coding. For each child code run Explore → Text Search Query with its pattern, spread to the page, and save results as code. Uncode Acknowledgement of Country passages from the Country codes.
  4. Review. Read a sample of references with coding stripes on, uncode false matches and record precision in a memo.
  5. Queries. Word Frequency (minimum length 4); Matrix Coding (themes × themes, “Coding at rows AND columns”; themes × Stratum attribute); Cluster Analysis by coding similarity (Jaccard).
  6. Framework matrix. Cases as rows, six themes as columns; summarise each cell with page references.
  7. Statistics. Export the matrix to Excel; χ² per pair with COUNTIFS and CHISQ.TEST; fit saturation with Solver.

Gephi

  1. Import nodes (Id, Label) and edges (Source, Target, Weight), undirected, merge “sum”; keep pairs with χ² > 10.83 and positive association.
  2. Layout ForceAtlas2: scaling 10, gravity 1.0, edge weight influence 1.0, prevent overlap.
  3. Statistics in order: Average Degree, Graph Density, Network Diameter (normalised betweenness), Modularity (weights on, resolution 1.0).
  4. Node size by betweenness, colour by modularity class, edge width by weight; export SVG or PNG at 4,000 px.
